# Customer Churn Prediction and Segmentation

## Project Overview
This project analyzes customer churn using machine learning and groups customers into meaningful segments using K-Means clustering. The goal is to identify customers who may leave a service and help businesses develop better customer retention strategies.

## Objectives
- Analyze customer churn patterns.
- Identify factors associated with customer churn.
- Predict churn using Logistic Regression and Random Forest.
- Segment customers using K-Means clustering.
- Evaluate model performance using precision, recall, F1-score, and confusion matrices.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature encoding and scaling
4. Machine learning model training and evaluation
5. Customer segmentation using K-Means
6. Churn probability and classification threshold analysis

## Key Findings
- Overall churn rate: approximately 26.54%.
- Month-to-month customers had a higher churn rate than customers on longer contracts.
- Balanced Logistic Regression achieved approximately 78% recall for churn customers at the default threshold.
- K-Means clustering identified four customer segments.
- Lowering the classification threshold increased churn recall to approximately 87%, with more false positives.

## Business Value
The analysis can help businesses identify at-risk customer groups, prioritize retention efforts, and understand customer behavior.
